# The Bongard representation problem

A proof over a visual description cannot establish that the description is
true of the pixels. The missing object is a candidate-independent empirical
witness with an explicit scope of competence.

## Authority boundary

```text
pixels -> typed observations -> closed predicate -> replayable decision
```

The first arrow is empirical. It may use deterministic geometry, a calibrated
observer, or both, but it must bind exact panel bytes, name the observed
objects, preserve uncertainty, and distinguish absence from failure. The
later arrows are deterministic Python.

Python is canonical. Lean may check consequences of persisted canonical JSON,
but it is optional and cannot supply visual truth, change an identity, select
a formula, authorize a query, or alter a decision.

## Candidate independence and four-valued evidence

A candidate-independent observer sees a neutrally named panel, not its task
side, support/query role, label, proposed formula, or target program. It emits
the complete registered inventory rather than facts chosen to support a
current guess.

Every observation has one of four dispositions:

- `present`: an affirmative witness exists;
- `certified_absent`: the exact observer scope licenses exclusion;
- `indeterminate`: the observer cannot decide within that scope; or
- `error`: extraction, transport, integrity, or evaluation failed.

`indeterminate` and `error` are never false. The closed language therefore
has no `Not`, complement search, polarity repair, or reroll.

## Skeleton-graph advance

The current deterministic observer combines four image scales into 112
features covering components, holes, bounding geometry, skeleton mass,
endpoint and branch clusters, raster cycle rank, edge orientations, turn
classes, and stroke-width summaries. Its fixed two-head 32-tree model emits a
33-class straight/arc probability vector and a three-class catalog vector.

The development diagnostics passed their frozen engineering thresholds, but
they are adaptive known-carrier evidence, not a benchmark or novel-carrier
claim. An exact passed-fit protocol authenticates the development precommit,
model, features, predictions, result, and cold replay. It does not authorize
calibration or target pixels by itself.

The inference layer is deliberately role-free. Equal PNG payloads share one
content-addressed row. Fresh verification re-extracts and re-infers; cold
replay verifies canonical records and joins without pixel or model calls.
Task identity, side, ordinal, truth, formula, and query role do not enter that
record.

The calibration core then separates raw prediction from truth. A valid run
would have to write, fsync, freshly reload, and independently verify every raw
prediction before constructing its delayed label reader. Whole-task
split-conformal scores and typed projections are frozen in advance. The
runner contains no CLI or built-in corpus, action-program, target, support, or
query loader.

These are real representation and custody advances. They are not evidence
that calibration ran.

## Synthetic representation experiments

### Phase 0: disconnected ordered-path control

The carrier-held-out failure identified a representation error: 112 global
scalars preserve silhouette statistics but discard ordered path incidence and
visible action boundaries. The new synthetic-only experiment therefore keeps
the ordered skeleton graph, fits maximal path spans as lines or circular arcs,
and returns a set-valued count when multiple equally small programs under the
bounded sampled fit grammar survive. It never claims to recover an invisible
generator boundary or a universally minimal raster explanation.

The synthetic renderer covers all 54 legal count pairs, records exact sorted
per-action ink-pixel indices, and instantiates each pair in five carrier
families under four D4 nuisances at fixed stroke width 2 and scale 1000. Three
complete families provide 648 training rows (641 unique PNGs); two
D4-raster-orbit-disjoint families provide 432 held-out rows (425 unique PNGs).

The target is not generator history. It is a partial pure function of the PNG:
each 8-connected ink component must exactly reproduce one finite line raster
or one finite annular-sector raster. If any component has no such singleton
normal form, the panel target is unresolved. Exact line/arc predicates check
all 4,096 raster pixels. Candidate fits are independently constructed, but a
post-fit target-resolvability gate suppresses any singleton for an unresolved
raster. The target does not choose a pair; unresolved set/GAP safety is still
a policy guarantee rather than independent observer evidence. Consequently
identical PNG bytes always have identical target state.

The collision audit contains ten exact hidden-history alias cases and one near
case. The endpoint-branch and line-chain/arc aliases are repeated under both
identical disconnected context and identical touching context. Disconnected
context preserves the componentwise scalar target; the two touching-context
cases instead make the connected component unresolved, and the post-fit gate
emits a set or GAP rather than a false singleton. The nine-case structural audit has
eight unresolved connected cases, all handled as set/GAP, and one resolved
legal shallow arc, which is identified. Ambiguity and GAP remain in fixed
metric denominators.

On the current synthetic split, the ordered observer is 432/432 joint-count
singleton-correct on the two held-out families, versus 189/432 for the freshly
fitted 112-feature pooled control on the same PNGs, a paired difference of
+243/432. The family breakdown is 216/216 versus 115/216 on `radial`, and
216/216 versus 74/216 on `staggered`. This is deliberately an easy,
disconnected, exact-component mechanistic benchmark. With only two held-out
carrier clusters, its family breakdown is descriptive: it supplies neither a
confidence bound nor a claim that connected action boundaries or broad visual
generalization have been solved.

This is active synthetic engineering, not an official successor campaign. It
has no corpus loader, filesystem input, CLI, calibration, official or
corpus-facing target/query input, or benchmark authority. Its synthetic PNG
target is local to this experiment. The terminal custody GAP and every
official prohibition below remain unchanged.

### Phase 1: connected fixed-catalog inversion

A second synthetic phase exercises actual within-shape `LL`, `LA`, `AL`, and

families each contain all 54 single-shape count pairs plus 52 two-shape
layouts under two nuisance regimes. Three whole families supply 636 training
rows; `radial` and `staggered` supply 424 held-out rows. All 1,060 PNGs are
unique, and the complete eight-element D4 raster orbits have zero cross-role
overlap.

The raw observer sees only exact PNG bytes previously issued by the
process-local synthetic renderer and a fixed catalog of line and arc masks.
That SHA-256-keyed issuance check records in-memory fixture provenance; it is
not a digital signature, external-file authentication, or official release
authority. The observer traces the skeleton graph, retains every
minimum-cardinality catalog cover, and requires exact foreground
reconstruction (XOR zero, IoU one). Held-out targets are exhaustive
PNG-plus-catalog covers constructed after raw outputs, and monkeypatch tests
prove that the raw API never calls
the target oracle. This is still not unseen-grammar induction: the raw
observer and target share the complete fixed catalog, including held-family
geometry. In a target-free dependency audit that removes every held-family-
only catalog mask, 0/424 held-out PNGs have any exact cover (0/216
single-shape and 0/208 two-shape).

The raw observer is 424/424 target-set correct and exact-reconstructing,
versus 106/424 for a freshly fitted fixed-32, 112-feature pooled control, a

This phase is fixed-catalog synthetic inversion evidence only. It does not

### Phase 2: program rules without ambiguity collapse

The semantic bridge now retains every complete minimum program hypothesis in
a canonical role-free observation. Its frozen language has 399 formulas: 32
single count/mix atoms and 367 cross-axis two-atom conjunctions. Each complete
formula is evaluated independently on each hypothesis and then supervaluated.
It is `present` only when all hypotheses satisfy it, `certified_absent` only
when all falsify it, and otherwise `indeterminate`; extraction failure remains
`error`. This whole-formula operation preserves correlations that independent
marginal cells cannot represent.

The support proof is the complete 399 by 12 matrix. A survivor must be present
on all six primary supports and certified absent on all six contrasts. The
deterministic freeze selects the minimum-arity survivor and then its digest.
Its typed zero-survivor record distinguishes a genuine language gap from
observer error or unresolved support ambiguity. An official-custody adapter is
implemented but dormant: it accepts only already released panels, binds the
precommitted observer/catalog/policy, persists the exact freeze and commit,
and passes the query gate only with those exact typed records.

Tests exercise that chain using synthetic bytes in a temporary official-shaped
TRAIN archive. This is protocol validation, not an official task result. The
fixed-catalog observer is not validated for official geometry, and the current
registry continues to authorize no official execution.

## Custody GAP is not a semantic GAP

The attempted calibration campaign ended before execution because an
overbroad repository search streamed official HD action-program material
before the prediction barrier. The incident conservatively marks all 4,400 HD
programs preexposed. It opened no PNG, ZIP, or archive bytes, wrote no files,
and ran no model or prediction.

The incident was persisted as a write-once exposure child and fixed campaign
tombstone. A fresh process-local verification capability was then required to
construct the canonical custody GAP
`sha256:9e53320d9aebd0d07dc61e60f8709c445db66936462fa9997613b645ecfba2ef`.

The GAP records zero post-tombstone model, pixel, label, rank, query, and
formula-evaluation calls. No support matrix, typed inventory, version space,
or predicate was constructed. Consequently:

- `version_space_digest`, `evaluated_formula_count`, and `survivor_count` are
  `null`, not zero;
- there is no semantic empty-space evidence; and
- no calibration, target, support, query, official-test, ranking, production,
  or benchmark authorization exists.

A semantic GAP would say that a fixed observation inventory and complete
registered language contain no support-consistent formula. This record says
only that the evidence chain was contaminated before that question could be
asked.

## Program exposure and pixel exposure

Program semantics, panel pixels, and labels are different authorities. The
incident conservatively exposes the HD program authority, including TEST
programs if they were resident in that file. It does not claim that TEST panel
pixels or labels were opened. Conversely, unopened pixels do not restore a
program-blind benchmark after its target programs have been seen.

Older exact-image-unused and task-exposure totals remain valid only at their
named historical ledgers. They must not be promoted into a current clean
cohort claim.

## Intended successor

For an independently clean future authority, the intended order remains:

```text
pixels
-> typed geometry and calibrated soft observations
-> deterministic support-consistent version space
-> typed language/witness/search gap if empty
-> Codex ranks verified candidates if nonempty
-> frozen Python predicate
-> query release and evaluation
-> model-free replay
```

The terminal campaign cannot be resumed or repaired in place. Re-entry needs
a new campaign identity, a demonstrably unexposed cohort/program authority,
new write-once stores, and a new preregistration. See
[`CONTINUATION_PLAN.md`](CONTINUATION_PLAN.md).
