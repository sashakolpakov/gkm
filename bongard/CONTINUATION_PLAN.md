# Bongard continuation plan

The frozen five-task headless **representation-engineering** campaign on
exact-unused TRAIN tasks with already exposed semantics is complete: 2/5
jointly correct and 4/10 on the fixed query denominator. The next useful work
is to repair witness/language coverage and add a typed empty-version-space
outcome before asking the proposer to rank anything. The
reserved non-test DEV set must wait: none of its 15 intended concepts is fully
expressible in the current v3 predicate language. Reaching a real DEV
benchmark requires finishing the Python visual representation, not adding a
theorem prover or searching for a complement of a failed rule.

## Non-negotiable protocol

Every live episode must follow this order:

1. Authenticate the release and select an unused non-test task from metadata.
2. Publish only hiding schedule commitments; never publish a digest over the
   49 possible omitted-index pairs without a secret nonce or key.
3. Freeze source identities as immutable plan fields and verify them again
   immediately before exposure.
4. Persist and cold-read the successor exposure ledger before opening pixels.
5. Acquire an exclusive campaign lock and durably claim a task before its one
   proposer call. Recovery may terminalize an unfinished claim but never call
   it again.
6. Authenticate every opened support and query PNG against the pinned official
   release manifest, including its canonical relative path and byte digest.
7. Observe all support panels independently into exact Python packets.
8. Optionally observe a complete neutral object-by-soft-tag inventory.
9. Give the proposer only support observations and support labels.
10. Accept one closed positive same-binding predicate; do not reroll it.
11. Evaluate it on all supports. Any positive `indeterminate`/`error` or any
   negative result other than `certified_absent` fails the exact gate.
12. Persist and cold-read the formula and source/algorithm identities.
13. Only then release query pixels and make the joint prediction.
14. Commit predictions before label materialization, then reveal labels.
15. Replay extraction and evaluation without a model and verify every digest.

The official test split remains unavailable throughout. No `Not`, polarity
flip, disjunction, complement rescue, or reroll is allowed.
