# Bongard visual predicates

This directory contains the Python-first ShapeBongard work. The intended
system turns exact panel bytes into candidate-independent typed observations,
constructs a deterministic support-consistent version space, freezes one
positive Python predicate, and opens query panels only after that freeze.

The current skeleton-graph campaign did **not** reach that endpoint. It is
terminally recorded as a custody GAP because official HD action-program
material was exposed before the prediction barrier. The canonical GAP is
[`data/panel_action_count_skeleton_graph_custody_gap_20260810_v1.json`](data/panel_action_count_skeleton_graph_custody_gap_20260810_v1.json),
record digest
`sha256:9e53320d9aebd0d07dc61e60f8709c445db66936462fa9997613b645ecfba2ef`.

## Current boundary

The incident conservatively treats all 4,400 HD action programs as
preexposed. That is a program/semantic custody failure, not a claim that all
HD images or labels were opened. The incident command opened no PNG, ZIP, or
archive bytes, wrote no files, and executed no model or prediction. Official
TEST panel pixels remain unopened by this campaign, but the documentation no
longer describes the HD program authority as sealed.

After the tombstone was durably verified, the typed GAP recorded zero model,
pixel, label, rank, query, and formula-evaluation calls. It also records:

- no support matrix or typed-axis inventory;
- no constructed version space, with its digest and counts left `null`;
- no semantic empty-version-space evidence;
- no frozen Python predicate; and
- no calibration, support, target, query, official-test, ranking, adapter, or
  benchmark authorization.

This distinction is essential. A custody GAP says that the causal evidence
chain is unusable. It does not say that the predicate language has zero
support-consistent formulas.

## Implemented advance

The failed custody boundary does not erase the engineering progress that
preceded it:

- a fixed 32-tree, 112-feature skeleton-graph observer over four deterministic
  image scales;
- an exact passed-fit authority that authenticates the complete development
  artifact and cold-replay chain;
- role-free raw inference custody that deduplicates equal PNG bytes and emits
  only content-addressed features and probability vectors;
- metadata-only preregistration for separate generic and same-family
  split-conformal calibration populations;
- a staged calibration runner that durably writes and freshly verifies raw
  predictions before delayed labels can be constructed; and
- crash-safe incident persistence and a model-free, metadata-only terminal
  GAP replay.

Exact commits, source addresses, record digests, validation results, and
limitations are collected in [`ADVANCES.md`](ADVANCES.md).

## Intended pipeline

```text
pixels
-> typed geometry and calibrated soft observations
-> deterministic support-consistent version space
-> typed language/witness/search gap if empty
-> Codex ranks verified candidates if nonempty
-> frozen Python predicate
-> query evaluation
-> model-free replay
```

Python is the executable and semantic authority. Lean is optional, removable,
and cannot provide visual truth or change an artifact identity or decision.
Evidence remains four-valued: `present`, `certified_absent`, `indeterminate`,
and `error`. Failure or uncertainty is never converted to Boolean false, and
the predicate language has no negation, polarity rescue, or reroll.

No current live plan is authorized. [`CONTINUATION_PLAN.md`](CONTINUATION_PLAN.md)
defines the evidence required for a new, independently clean campaign. It is
not permission to reuse the terminal campaign, its target family, its stores,
or the preexposed HD program authority.

## Historical results

Earlier campaigns remain useful, immutable engineering evidence:

- the 24-task coverage pilot extracted 336/336 panels but found no exact
  separator in its historical relational diagnostic language;
- the five-task exact-image-unused TRAIN campaign over already disclosed
  generator semantics was 2/5 jointly correct and 4/10 on its fixed query
  denominator; and
- the three-task panel-soft drill made 75 receipted calls and correctly ended
  with zero support-consistent formulas, zero ranker calls, and zero query
  releases.

These are preserved historical diagnostics, not current launch authority,
strict DEV results, official TEST results, or unbiased generalization
estimates. See [`HISTORY.md`](HISTORY.md) and the frozen
[`PANEL_SOFT_EXACT_UNUSED_TRAIN_20260809_RESULT.md`](PANEL_SOFT_EXACT_UNUSED_TRAIN_20260809_RESULT.md).

Historical exposure counts such as 156, 180, 185, and 314 task IDs describe
their named ledger checkpoints. They are not interchangeable with the later
program-exposure incident. Exact-image exposure and program-semantic exposure
are tracked as different facts.

## Retirement

The obsolete panel-soft, prompt/multiview/decomposition, CNN-v1/v2/spatial,
and July symbolic executors are physically removed and registered as
non-executable. The two retirement cuts removed 19 production modules and 14
obsolete tests, deleting 26,697 lines.
Their exact source preimages remain inert audit data in
[`data/panel_retired_pipeline_source_snapshot_20260810_v1.json`](data/panel_retired_pipeline_source_snapshot_20260810_v1.json),
record digest
`sha256:1e454e0d175ad7971608404005dfa59340c6dbeae1d8a52490b7d97fa84825dd`.

[`pipeline_registry.py`](pipeline_registry.py) is the descriptive lifecycle
ledger. It reports no active successor and no new-execution authority. It is
not automatically consulted by every retained direct module, so source
presence is not permission to run it. Historical command names in records and
prose do not imply that deleted or retained audit modules may be launched.
