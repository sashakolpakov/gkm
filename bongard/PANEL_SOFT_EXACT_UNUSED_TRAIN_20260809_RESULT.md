## What vision produced

The proposer did produce useful soft language, including `birdlike gestalt`,
`convex enclosure`, `elongated span`, `upright arrangement`, and several
open/closed and contact-like relations.  It also exposed four defects.

1. **It selected salience, not discrimination.**  The prompt requested
   recurring visible qualities and prohibited contrast/comparison language.
   BD consequently proposed `Two spatially separated forms compose each
   drawing` independently for both orientations.  Downstream code then
   demanded perfect 6-vs-6 discrimination from candidates never selected for
   that purpose.
2. **The atoms were compound and owner-free.**  Phrases could pool a compact
   cluster, a distant chain, a perimeter, and an enclosure without stable
   panel-local subject identities.  More specifically, the proposer supplied
   two cross-panel example clauses for each atom, but the observer prompt
   required the phrase and **all** of those clauses together on every
   individual panel.  Examples such as a patterned oval and a long kite thus
   became an accidental conjunction, inflating disagreement and rejecting
   otherwise useful phrases.
3. **Affirmative wording did not establish affirmative semantics.**  `broad
   enclosure` can be the semantic sibling of an open-trace distinction, and
   `irregular arrangement` is a residual absence-of-regularity concept written
   without the word `not`.
4. **The task-relevant observable could be omitted.**  For
   `hd_convex-has_four_straight_lines_0001`, the proposer never nominated
   exact four-straight-line structure.

The lexical filter therefore did its narrow job but could not close the
semantic hole.

## The theoretical hole

For a positive existential feature, vision can establish presence with a
witness:

```text
there exists an eligible owner with a valid feature witness
```

The support separator also needs contrast-side falsity.  Failure to find a
witness is not falsity.  A rigorous negative requires:

```text
frozen finite eligible-owner set
+ complete search at declared resolution
+ typed rejection evidence for every eligible owner
```

Without that completeness certificate, the only sound result is
`indeterminate`.  The current version space correctly requires every native
support to be `repeated_present` and every contrast support to be
`repeated_mismatch`.  One native disagreement kills an atom; one unresolved
contrast panel prevents separation.  Conjunction can combine certified
nonmatches, but cannot repair a native miss or turn uncertainty into absence.

This creates a structural squeeze:

- treating failed search as negative resurrects the false-negation bug;
- keeping failed search indeterminate makes open-prose existential candidates
  systematically fail exact 6-vs-6 separation;
- allowing `Not` or polarity flipping lets the complement of a weak or
  overbroad predicate win finite-support search without acquiring better
  visual evidence.

That explains the old observation that a synthesized predicate was so poor
that its negation won.  The failure was upstream: weak, nuisance-heavy
measurements plus an invalid complement/absence escape hatch.  In this drill
the escape hatch was removed, so the honest outcome was an empty version space
before ranking.

Lean cannot repair this.  It can prove that a Boolean formula follows from
declared observations; it cannot prove that the vision model found every
eligible owner in a panel.  Python is sufficient for the executable semantics
and is already the canonical implementation.

## Required next pipeline

The next implementation should be:

```text
pixels
-> contrastively nominated typed FeatureSpec values
-> panel-local owners and family-specific witnesses
-> calibrated presence or certified exhaustive-search absence
-> deterministic support-consistent version space
-> typed language/witness/search-completeness gap if empty
-> Codex ranks verified survivors only
-> frozen Python predicate
-> query release and evaluation
-> model-free replay
```

The minimum Python-native types are:

- `FeatureSpec(family, subject_scope, reference_frame, closed_parameters)`;
- stable panel-local `OwnerId` values and an owner/relation graph;
- family-specific positive witnesses, such as endpoints, corners, segments,
  contacts, gaps, enclosures, and gestalt rubric cues;
- `AbsenceCertificate(eligible_owners, per_owner_rejections,
  search_complete, resolution_domain)`;
- a calibration authority that enables presence and absence separately for an
  exact observer contract and feature domain.

Candidate nomination must reason contrastively while emitting affirmative
panel-local claims.  Identical typed specs must be deduplicated across
orientations.  Registered sibling variants such as open/closed or
contact/visible-gap are allowed only with explicit exclusivity and
exhaustiveness declarations; residual prose such as `irregular` is rejected.

The first ontology expansion should cover component count, exact segment
count, marker primitive/repetition, open trace, closed loop, enclosure,
point-contact/visible-gap, shared-boundary adjacency, segment orientation,
corner angle, aspect ratio, texture composition, symmetry, and calibrated
gestalt resemblance.

Near-miss scores and calibrated uncertainty bounds should be reported for
diagnosis, but must not silently weaken the authoritative gate.  Same-model
repeats are one noisy measurement instrument, not independent scientific
replication.
